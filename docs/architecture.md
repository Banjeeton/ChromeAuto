# Архитектура расширения

## Порт AutomationEngine

`AutomationEngine` — граница между прикладной логикой автоматизации и
браузерным драйвером.

```text
core/application -> core/ports/AutomationEngine <- adapters/playwright
```

Core отвечает за порядок шагов, состояния сессий, повторные циклы и правила
остановки. Реализация порта отвечает только за управление вкладкой и выполнение
одного доменного шага. Типы `Browser`, `BrowserContext`, `Page` и другие детали
Playwright CRX не должны пересекать границу порта.

Жизненный цикл одной сессии:

1. `start` привязывает идентификатор сессии к целевой вкладке.
2. `executeStep` выполняется для каждого включенного шага пресета.
3. `complete` освобождает ресурсы после успешного выполнения.
4. `stop` отменяет одну сессию по запросу пользователя или после ошибки.
5. `stopAll` отменяет все активные сессии.

Исключения конкретного драйвера преобразуются в `AutomationEngineError` со
стабильным доменным кодом и контекстом сессии или шага. Исходная ошибка может
быть сохранена в `cause` для журнала, но прикладная логика не должна зависеть от
ее типа.
